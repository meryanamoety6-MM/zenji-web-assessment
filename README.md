# ZENJI — HTML / CSS / JavaScript

Frontend-only ZENJI Web Developer assessment project.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for demo cart

## Pages
Home, Shop, Product Details, Cart, Our Story, Lookbook, FAQ.

## Run
No Node.js or npm is required. Open `index.html` directly, or use VS Code Live Server.

## Features
Responsive layout, product filtering/search, product details, size/quantity selection, localStorage cart, demo checkout, mobile navigation, hover effects, marquee and scroll-reveal animation.

## Deployment
Upload this folder to GitHub and publish with GitHub Pages, Netlify, or Vercel as a static site.


## Assessment version
- Frontend only: HTML, CSS and JavaScript.
- Product names are original ZENJI-inspired names.
- Product imagery is provided locally in `assets/products/`.
- No backend, database, authentication or payment integration.
